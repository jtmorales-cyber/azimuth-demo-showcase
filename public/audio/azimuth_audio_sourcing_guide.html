1. How to Use This Guide

For each of the 13 files referenced in public/audio/audioMap.ts, this guide gives you a Primary pick (highest-confidence match for the spec) and a Backup pick (alternate if the primary doesn't fit your ear or gets pulled). Every URL goes to a Pixabay asset page where you click Download → MP3, then rename to the exact filename in the file-card header.

All Pixabay assets shown carry the Pixabay Content License: free for commercial use, no attribution required, modification permitted. None require account login to download.

Workflow: Download → preview in your DAW or browser → rename file to the spec name → drop into public/audio/ → restart npm run dev. Per the README, the AudioEngine has graceful fallback, so you can drop assets in piece-by-piece and test as you go. After all 13 are present, DevTools Network should show 13 × 200 responses and zero console.warn from the engine.

4. Editing Notes — Trimming and Loop-Smoothing

Eight of the 13 files match the spec lengths exactly. The other five need light editing. Use Audacity (free, open-source) or any DAW you already have:

  1. Trim "soft startup sound" 0:03 → 1.8s — keep the rise, fade out at the peak. (boot-tone)
  2. Trim "uplifting pad texture" 1:36 → 45s seamless excerpt — find a quiet zero-crossing, cut, apply a 1s crossfade between start and end. (maps-harmonics)
  3. Trim "Soft Harmonic Breath – Short" 0:43 → 1.5s — pick the cleanest single-breath cycle, fade in 100ms, fade out 200ms. (breathing-ambient)
  4. Loop-smooth "Industrial-Pulse-Drone" — usually fine as-is, but if you hear a click at the loop boundary, apply a 200ms crossfade in Audacity (Effect → Crossfade Tracks). (gauntlet-ambient)
  5. Loop-smooth any other 30–60s loop with audible boundary clicks — same technique. Howler.js doesn't crossfade between loop iterations, so the file itself must seam.

Export everything at 128 kbps MP3 (a 33s file ≈ 480 KB; total payload stays well under the 5 MB target).

5. Verification — After Drop-In

  1. Files placed in public/audio/ with exact filenames.
  2. npm run dev → open localhost:3000
  3. DevTools → Network tab → reload. Confirm 13 × 200 OK on /audio/*.mp3. Any 404 means a typo in the filename.
  4. DevTools → Console. The AudioEngine logs [AudioEngine] Failed to load… on missing files. Should be silent.
  5. Click "TAP TO BEGIN" — boot-tone fires once, then crossfades to hub-pad over 2.5s.
  6. Hover a tool node — chime plays. Tap a tool node — scene crossfades to that drone.
  7. Inside any sanctuary, swipe to advance a card — the sanctuary's interaction one-shot fires.
  8. Tap the Azimuth back button — hub-pad continues seamlessly during the return flight.

6. Risk & Caveats

BASE trauma-informed audio risk. The BASE scene is the one place where audio choice can backfire. Avoid: literal human breathing samples, Tibetan bowls, "binaural beats", "528Hz healing", "chakra" anything. These read as new-age clinical-adjacent rather than neutral wellness. Stick to plain warm pad textures (the picks above honor this). When in doubt, run any new BASE candidate through your nova-safeguard + nova-mindhunter skills before committing.
